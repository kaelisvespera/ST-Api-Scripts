# ST-Api-Scripts

SillyTavern（ST）与 TauriTavern 2.4（TT）的 API 配置管理器。本文对应 **2.2.10**。

## 使用

原生扩展通过酒馆的「扩展 → 安装扩展」安装，地址为 [kaelisvespera/ST-Api-Scripts](https://github.com/kaelisvespera/ST-Api-Scripts)。升级时先停用旧 API 管理器脚本，再刷新酒馆。原有配置无需删除。通过魔法棒扩展菜单的「API 管理」打开，也可使用 `/st-api-manager`。在「数据 → 入口设置」选择魔法棒、QR（Quick Reply）或同时启用。QR 使用酒馆的 Quick Reply 功能；该功能不可用或未启用时，魔法棒入口会保留。

- 主面板沿用 API 管理、标签设置、筛选、检测和数据工具栏，配置按标签折叠展示。每个分组和「未分类」的展开状态保存在当前酒馆，重启后恢复。通过「API 管理」可新增或编辑一个站点的多把 Key 和多个模型。
- 在「标签设置」拖动排序柄，可调整主界面标签分组顺序。在主界面点分组旁的「排序」，底栏切换为拖动排序柄和上移、下移按钮，也支持方向键。每次移动自动保存，点「完成」或按 Escape 退出；拖动过程中按 Escape 只取消本次拖动。排序会保存；同一配置在多个标签中的顺序分别记录。筛选时只调整可见配置的顺序，隐藏配置保留原位置。
- 「拉取模型」使用表单当前选中的 Key，未选时用列表第一把。每把 Key 各有模型列表，可多选模型并为每条配置选标签。同 URL、同模型下的不同 Key 独立保存。站点若限制跨域访问，可手动填写模型。
- 在密钥掩码下方填写「密钥备注」，在各个模型 ID 下方填写「模型备注」。例如给一把 Key 写「CCMAX」，再给它下面的某个模型写「0.5/次」。同一配置组内同一条密钥记录的模型共享密钥备注，每条模型各自保存模型备注。清空后点「保存」可移除备注。旧「条目备注」仍可在单条编辑中使用。
- 卡片上方显示模型、当前组名和两级备注。组名与备注同字号，长内容默认收起为一行；点模型名展开，再点「完整详情」查看原条目标题。五个原有图标按钮集中在底部同一排，未分类卡片沿用四个适用操作。日常模式点击卡片文字或空白处也可应用，按钮与文本选取不会误触应用，排序模式不应用配置。卡片背景、文字和边框跟随 ST / TT 主题。
- 「标签设置」可按当前组名、模型 ID、原条目标题和两级备注搜索。同组同名模型会显示 Key 序号，便于选中对应密钥的条目。长标签名称自动换行，编辑和删除按钮分别占位。底部操作仅用文字，宽度不足时整组换行。
- 「检测」和「发送测试消息」直接请求指定站点。测试消息需要先选定表单中的 Key 和模型。
- 导入可选择合并或替换，支持旧版数组和分组导出。账户冲突时可以使用账户数据、使用本机数据、合并或取消。合并保留独立副本，可选同名标签的颜色。导出文件和账户存档包含密钥，请按私有资料保存。

2.2.2 移除了编辑页的 Key 轮换开关和聊天时自动换 Key。配置编辑、导入、同步和模型拉取只管理目录。

## 数据与验证

旧站点、分组和密钥池按独立条目迁移。原始存档和旧账户快照保留，可用于回退；新版编辑不会写回旧快照。实现和恢复方式见 [架构与实现](docs/架构与实现.md)。

```sh
node tools/build.cjs
node --experimental-vm-modules --test tests/*.test.cjs
node --test tests/*.browser.cjs
```

本地通过 48 项 Node 回归和 31 项 Edge 浏览器测试。另以 ST、TT 原生及旧 TT iframe 三种夹具验证了实际上游 Quick Reply API 与集合类。浏览器验收使用 ST、TT 和旧 TT iframe 的隔离夹具，覆盖拖动、触摸与边缘自动滚动、取消、保存失败重试、筛选后排序、重载与账户同步，以及 QR 入口切换、延迟加载和用户集合保护。既有编辑返回、分组展开、导入和长标签排版回归保持通过。视口包含 320px 手机、平板、横屏和桌面。手机和真实服务商尚待实测。原生安装无需酒馆助手，五个旧导入 JSON 对应历史脚本版本。
